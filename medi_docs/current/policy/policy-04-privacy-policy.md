# 개인정보처리방침 (초안 — 법무 검토 전)

## Summary

한국 개인정보보호법 기준 개인정보처리방침 초안. 수집 항목, 이용 목적, 보유 기간, 제3자 제공, 사용자 권리를 정의. `[TBD]` 항목은 사용자 검토 후 확정. Phase 2 진입 전 법무 검토 필수.

> **주의**: 이 문서는 초안입니다. 실제 서비스에 적용 전 반드시 법무 검토를 받으십시오.

---

**Summer Star company** (이하 "회사")는 개인정보보호법에 따라 이용자의 개인정보 보호 및 권익을 보호하고 관련된 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다.

---

## 제1조 (수집하는 개인정보 항목)

### 1-1. 회원가입 시 (OAuth 인증)

| 항목 | 수집 방법 | 필수/선택 |
|------|---------|:-------:|
| 이메일 주소 | Google/Apple OAuth | 필수 |
| OAuth Subject ID (provider_id) | OAuth 토큰 | 필수 |
| 이름 (표시명) | OAuth 프로필 | 선택 |

### 1-2. 서비스 이용 시 자동 수집

| 항목 | 수집 방법 | 비고 |
|------|---------|------|
| 기기 정보 (OS, 앱 버전) | 서비스 이용 시 | 오류 분석 목적 |
| IP 주소 | 서비스 접속 시 | 보안·남용 감지 |
| 접속 로그 (API 요청 기록) | 서비스 이용 시 | 이상 행동 감지 |
| Timezone (시간대) | 가입 시 / 앱 설정 변경 시 | 일일 한도 리셋 기준 |
| 약관 동의 시각 (`terms_agreed_at`, `privacy_agreed_at`) | 동의 버튼 클릭 시 | 법적 동의 이력 |

### 1-3. 서비스 이용 생성 데이터 (서버 저장)

| 항목 | 비고 |
|------|------|
| 녹화 세션 메타데이터 (시작 시각, 길이, 해상도, 상태) | 영상 파일 자체는 사용자 기기에만 저장, 서버 미전송 |
| 일일 포커스 통계 (session_count, total_seconds) | 한도 체크 및 통계 목적 |
| 스트릭 정보 (연속 학습 일수) | 서비스 기능 제공 목적 |

### 1-4. 결제 관련

| 항목 | Phase 1 | Phase 2 |
|------|---------|---------|
| 구독 이벤트 이력 (event_type, source, plan, amount_cents, occurred_at) | mock 데이터 | RevenueCat 영수증 메타데이터 |
| 결제 수단 정보 | 수집 안 함 | App Store / Google Play 직접 처리 (회사 미보유) |

---

## 제2조 (개인정보 이용 목적)

| 이용 목적 | 수집 항목 |
|---------|---------|
| 회원 인증 및 서비스 제공 | 이메일, OAuth ID, 이름 |
| 구독 상태 관리 및 결제 처리 | 구독 이벤트 이력 |
| 일일 한도 기능 제공 | 일일 포커스 통계, timezone |
| 서비스 개선 및 오류 분석 | 접속 로그, 기기 정보 |
| 법적 의무 이행 (결제 이력 보관) | 결제 이벤트 이력 |
| 고객 지원 및 민원 처리 | 이메일, 이용 이력 |

회원의 개인정보는 위 목적 외에 활용되지 않으며, 목적이 변경될 경우 사전 동의를 받겠습니다.

---

## 제3조 (개인정보 보유·이용 기간)

| 항목 | 보유 기간 | 근거 |
|------|---------|------|
| 회원 계정 정보 (이메일, OAuth ID, 이름) | **회원 탈퇴 시 즉시 삭제** | 수집·이용 목적 달성 |
| 녹화 세션 메타데이터, 포커스 통계 | **회원 탈퇴 시 즉시 삭제** | 수집·이용 목적 달성 |
| **결제 이벤트 이력** | **5년** | 전자상거래법 제6조 (계약·청약 철회 기록 보존 의무) |
| 약관 동의 이력 (terms_agreed_at) | **5년** | 동의 증명 목적, 전자상거래법 |
| 접속 로그 | **3개월** | 통신비밀보호법 |

---

## 제4조 (개인정보 제3자 제공)

원칙적으로 이용자의 개인정보를 외부에 제공하지 않습니다. 다음의 경우 예외:

| 제공 대상 | 제공 항목 | 제공 목적 | Phase |
|---------|---------|---------|-------|
| **Apple Inc.** | OAuth 인증 토큰 | 소셜 로그인 처리 | 1, 2 |
| **Google LLC** | OAuth 인증 토큰 | 소셜 로그인 처리 | 1, 2 |
| **RevenueCat Inc.** | 사용자 식별자(UUID), 구독 이벤트, 영수증 메타데이터 | 결제 처리·영수증 검증·구독 상태 관리 | **2 부터** |
| **AWS (Amazon Web Services, Inc.)** — ap-northeast-2 (서울) 리전 | 서버 내 저장 데이터 | 서비스 인프라 운영 | 1, 2 |

> **국외 이전**: Apple (미국), Google (미국), RevenueCat (미국) 에 데이터가 이전됩니다. 각 사의 개인정보처리방침을 병행 확인하십시오.

---

## 제5조 (국외 이전)

Phase 2 부터 RevenueCat Inc. (미국)에 구독 처리 목적으로 개인정보가 이전됩니다.

| 이전 대상 | 국가 | 이전 항목 | 이전 목적 | 보유 기간 |
|---------|------|---------|---------|---------|
| RevenueCat Inc. | 미국 | 사용자 UUID, 구독 이벤트, 영수증 메타데이터 | 결제 처리·영수증 검증·구독 상태 관리 | RevenueCat 정책에 따름 |
| Apple Inc. | 미국 | OAuth 인증 토큰, 인앱 결제 영수증 | 소셜 로그인·결제 처리 (Phase 2 스토어 환불 위임 포함) | Apple 정책에 따름 |
| Google LLC | 미국 | OAuth 인증 토큰, 인앱 결제 영수증 | 소셜 로그인·결제 처리 (Phase 2 스토어 환불 위임 포함) | Google 정책에 따름 |
| AWS (Amazon Web Services, Inc.) | 미국 — 한국 리전(ap-northeast-2) 처리 | 서버 내 저장 데이터 | 서비스 인프라 운영 | 서비스 탈퇴 시 삭제 / 법적 보존 기간 |

> [법무 검토 항목] EU/EEA 사용자 대상 서비스 시 GDPR 준수 여부 별도 검토 필요.

## 제7조 (쿠키·트래킹)

- **모바일 앱 특성상 쿠키 미사용**
- 앱 내 분석 도구: **미도입.** 별도 분석 SDK 를 사용하지 않으며, RevenueCat 결제 데이터와 자체 서버 로그만 사용합니다.
- 광고 추적 (IDFA/GAID): 현재 미사용. 사용 시 별도 동의 획득.
